SISTEMA / STREAM RADIO

Información de la aplicación

SR

Stream Radio

Versión 1.0.0

Aplicación de escritorio para transmitir audio en vivo hacia Zeno.fm / Icecast, desarrollada para UNIR Radio. Incluye biblioteca de pistas, monitorización en tiempo real, grabación y actualizaciones automáticas.

Repositorio: github.com/jhersara/Stream-Unirradio
